# map671-final-delicate-arch
Final GIS mapping project
Delicate Arch Terrain Analysis
By Joyia Burrus

Project Overview
For this project, I created a terrain map of the area surrounding the Delicate Arch in Arches National Park, Utah. Using DEM data obtained from the USGS, I generated hillshade and contour layers in QGIS see the elevation changes. The goal of this project was to create a map that represents the topography around using what I have learned in MAP 671.


Project Data
Data Source: United States Geological Survey National Map (USGS) DEM data. https://apps.nationalmap.gov/downloader/ 

Software Used: QGIS, Visual Studio Code and Github

Map Description
Using the DEM data, I created hillshade and contour layers in QGIS to show changes in elevation and overall landscape. Combined, these layers provde a better view of the topography surrounding Delicate Arch.
